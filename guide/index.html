电子书处理指南

书简是一个纯前端的电子书处理网页——把书拖进浏览器，得到一本处理好的书。繁简转换、竖排横排、日文注音，全都在你自己的设备上完成，文件不出本机。下面几页分别说清每项功能怎么用、能做到什么、又做不到什么。

书简是做什么的

书简把 EPUB、TXT 这类电子书读进来，只搬章节结构与文字，做完你要的变换，再导出成一本新书。字体、字号这些交给你的阅读器，它不替你决定排版细节。目前处理得最稳妥的是 EPUB 与 TXT 两种格式。

三件事它做得最顺：

  • 繁体转简体（也能简转繁）——词级转换，连用词习惯一起换。
  • 竖版转横版（也能反过来直排）——改的是 EPUB 的排版方向。
  • 日文注音（振假名）——给日文汉字逐词标上假名读音。

文件会不会被上传？

不会。书简没有后端、没有上传、没有任何 API 调用，你的书从头到尾都待在浏览器里。它唯一会联网的地方，是从公共 CDN 加载几个开源库、以及日文注音要用到的分词词典——那些是程序本身，不是你的文件。你甚至可以断网、把网页存下来离线打开，转换照样跑。

按需要选一页往下看

电子书繁体转简体 把繁体的 EPUB、TXT 转成简体，词级转换，可选台湾 / 香港用词。 电子书竖版转横版 把竖排右起的 EPUB 转成横排，也能反向做成直排。 电子书日文注音 给日文汉字标上振假名，带着假名进 Kindle、微信读书。 EPUB 与 TXT 处理方法 两种格式各适合什么、书简怎么处理、边界在哪。
