电子书日文注音 / 振假名（EPUB）

想读日文原著、又不想每个汉字都停下来查读音？书简能给日文汉字逐词标上振假名（ふりがな），带着假名进 Kindle、微信读书、Apple Books。

什么是振假名（ふりがな / furigana）

振假名（ふりがな，furigana）是标在日文汉字旁的小假名，注明这个汉字怎么读。日本的童书、教科书、给学习者的读物都会加。对在阅读里攒生词的人来说，它让你不打断阅读就知道读音，扫一眼就记住了。

振假名长这样（下面是真的 ruby，假名标在汉字上方） 日本語にほんご を 読よむ

日文电子书怎么加振假名 / 假名标注

书简走的是词级分词，不是逐字查表：

  • 用开源的 kuromoji 做日语分词，把句子切成词、拿到每个词的读音。
  • 读音从片假名转成惯用的平假名。
  • 用标准的 HTML <ruby> 结构把假名标在汉字上方——这是电子书通行的注音写法。

标注范围可选：

  • 全部汉字：每个汉字都标。
  • 只标生僻字：常见字不标，把假名留给真正难的字，页面更清爽。

Kindle 上的日文书能显示振假名吗

<ruby> 是 EPUB 通行标准，主流阅读器都支持良好：Kindle、微信读书、Apple Books、Kobo 等，都会把假名显示在汉字上方。

为什么第一次注音要等着下载 17MB 词典

第一次注音时，书简会加载日语分词词典（约 17MB），要等它就绪才能开始。这不影响隐私：分词和注音都在你的浏览器里完成，从网络加载的只有这份词典——它是程序的一部分，你的书不出本机、不会上传。词典之后走缓存，再处理别的书就不用再等了。

日文 EPUB 加注音的操作步骤

  1. 打开书简（点文末按钮回首页工具）。
  2. 功能切到「日文标音」。
  3. 标注范围选「全部汉字」或「只标生僻字」。
  4. 输出格式选 EPUB（TXT 存不下假名）。
  5. 把日语书拖进去，等词典就绪，点「开始转换」后下载。

Kindle、微信读书、Kobo：日文原版书怎么读到振假名

从青空文库拿的日文作品，或手里本来就无 DRM 的日文 EPUB，流程一样：先把文件存到电脑上，在书简里选「日文标音」处理一遍，得到带假名的新 EPUB，再放回阅读器——Kindle 用「发送至 Kindle」或数据线当个人文档导入，微信读书在网页端「上传本地书籍」，Kobo 把文件直接拷进设备。要说清楚：书简没有后端，也不接阅读器账号，不会替你同步；全程是你手动导出、本机处理、手动导入，文件始终在自己手上。

哪些情况标不出假名（注音的边界）

  • 只对日语书有用：它给的是日语读音，中文书用不上。
  • 生僻 / 未登录词可能没读音：分词词典没收的词，标不出假名，会原样留着。
  • 别同时叠加繁简转换：繁简词库会把一些日文汉字改成分词认不出的字形，导致那个字丢读音。给日语书注音时，繁简请选「不转换」。
  • 要用 EPUB，不能输出 TXT：振假名是 <ruby> 富文本结构，纯 TXT 是无格式文本，存不下标在汉字上方的假名。
